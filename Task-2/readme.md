# Task 2: Banking System in Java

## Project Overview
The Banking System is a beginner-friendly Java console application developed to demonstrate object-oriented programming concepts. It allows users to deposit money, withdraw money, and check their account balance through a menu-driven interface.

## Features
- Deposit money into the account
- Withdraw money when sufficient balance is available
- Check the current account balance
- Validate invalid deposit and withdrawal amounts
- Display a menu until the user chooses to exit

## Concepts Used
- Classes and Objects
- Encapsulation
- Methods
- Conditional Statements
- Loops
- Switch Statements
- User Input using Scanner

## Project Structure
- `BankAccount.java` — Manages the account balance, deposits, withdrawals, and balance retrieval.
- `Main.java` — Displays the menu and handles user interaction.

## Initial Balance
The account starts with a balance of 1000.0.

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Open the terminal in the folder containing both Java files.
4. Compile the classes:

   `javac BankAccount.java Main.java`

5. Run the application:

   `java Main`

## Sample Operations
- Initial balance: 1000.0
- Deposit: 500.0
- Withdraw: 200.0
- Final balance: 1300.0

## Learning Outcome
This project provided practical experience with Java classes and objects, encapsulation, methods, user input, conditional logic, and menu-driven console applications.
